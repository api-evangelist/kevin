# Kevin.

> kevin. was a Lithuanian account-to-account (A2A) payments infrastructure company providing PSD2 open-banking payment initiation and account information services to merchants across 28 European countries. This profile is generated by API Evangelist from kevin.'s published npm packages and archived developer reference; the company has wound down its public web presence (kevin.eu no longer resolves as of 2026-07).

## API

- [kevin. platform API reference (v0.3, archived)](https://api-reference.kevin.eu/public/platform/v0.3): Auth, General, Payment Initiation and Account Information services. Base URL: https://api.kevin.eu/platform
- [Developer documentation (archived)](https://developer.kevin.eu/): platform integration guides and webhook verification.

## Services & operations

- General Service: getCountries, getBanks, getBank, getSavingsBanks, getPaymentMethods, getProjectSettings
- Payment Initiation Service: initiatePayment, getPayment, getPaymentStatus, initiatePaymentRefund, getPaymentRefunds
- Authentication Service: startAuth, receiveToken, refreshToken, receiveTokenContent
- Account Information Service: getAccounts, getAccount, getAccountTransactions, getAccountBalance

## Packages

- [@kevin.eu/kevin-platform-client](https://www.npmjs.com/package/@kevin.eu/kevin-platform-client): official Node.js SDK.
- [@kevin.eu/kevin-cli](https://www.npmjs.com/package/@kevin.eu/kevin-cli): CLI for testing signed webhooks.
- [@kevin.eu/kevin-ui](https://www.npmjs.com/package/@kevin.eu/kevin-ui): React design-system UI components.
